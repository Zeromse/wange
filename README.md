# 挽歌燃烧殆尽 · 交互导览

基于用户提供的《明日方舟》SideStory「挽歌燃烧殆尽」活动录屏制作的单页展示网站。它将录屏中的活动入口、关卡路线、奖励兑换、剧情回顾和寻访画面整理成可浏览的导览。

## 运行方式

解压项目后，直接用浏览器打开 `index.html`。网站使用原生 HTML、CSS 和 JavaScript，无需安装依赖、注册账号或连接游戏服务。

如果浏览器限制本地视频播放，也可以在项目目录启动任意静态文件服务器，再通过服务器给出的本地地址访问页面。例如：

```bash
python -m http.server 8000
```

随后打开 `http://localhost:8000/`。

## 页面与交互

| 区域 | 内容与操作 |
| --- | --- |
| 首页 | 直接展示活动主题和录屏主视觉，可打开原始录屏的压缩版。 |
| 关卡路线 | 切换「摇曳的影」与「将熄的火」，选择 EA 关卡节点查看对应地图展示状态。 |
| 奖励兑换 | 依据录屏可见物品选择兑换组合，实时计算已选点数和预计余量；可清空选择。 |
| 影像档案 | 在「新火重燃」「照我以火」和回忆画集画面之间切换，并查看蚀刻章套组画面。 |
| 寻访画面 | 展示录屏最后出现的「自火中归还」界面。 |

页面支持桌面与手机布局、键盘操作、悬停及按钮状态。录屏播放器可从页面多处打开，关闭时会暂停播放。

## 文件结构

```text
.
├── index.html          页面结构和文案
├── styles.css          视觉样式与响应式布局
├── app.js              关卡、兑换、轮播、导航和视频交互
└── assets/
    ├── *.webp          从提供的录屏提取并优化的画面
    └── recording.mp4   供站内播放的压缩录屏
```

## 数据说明

- 页面中的名称、关卡编号、物品和点数取自提供的录屏。
- 兑换区的 **1,772 点**是录屏中的示例数值；选择物品只进行本地试算，不会改变游戏数据。
- 关卡节点选择用于导览展示，不代表游戏内解锁或通关状态。
- 素材与视频来自用户提供的资料；本项目是非官方展示作品。
